# 1. 技術トレンドのキャッチアップ

世界的なカンファレンス・学会を軸にした情報源の整理と、効率的にトレンドを追うための型。

## 1.1. 世界的な技術カンファレンス・学会

### 1.1.1. 学会組織（Society）

| 学会 | 分野 |
| --- | --- |
| ACM（Association for Computing Machinery） | 計算機科学全般 |
| IEEE（Institute of Electrical and Electronics Engineers） | 電気・電子・情報工学全般 |
| AAAI（Association for the Advancement of Artificial Intelligence） | AI全般 |
| USENIX | システム・セキュリティ系 |

これらの学会が主催・共催するカンファレンスが、発表の場として世界的な権威を持つ。

### 1.1.2. AI・機械学習系

- NeurIPS（Neural Information Processing Systems）: 機械学習分野最大規模・最難関
- ICML（International Conference on Machine Learning）
- ICLR（International Conference on Learning Representations）
- CVPR（Computer Vision and Pattern Recognition）: 画像認識・CV系
- ACL（Association for Computational Linguistics）: 自然言語処理系
- IJCAI（International Joint Conference on AI）

### 1.1.3. ソフトウェア工学・システム系

- ICSE（International Conference on Software Engineering）: ソフトウェア工学最高峰
- OSDI / SOSP: OS・分散システム
- SIGMOD / VLDB: データベース系
- WWW（The Web Conference）: Web技術全般

### 1.1.4. セキュリティ系

- Black Hat / DEF CON: 実務・ハッカーコミュニティ寄り
- IEEE S&P（通称 Oakland）/ USENIX Security: 学術寄り

### 1.1.5. 開発者向け実務カンファレンス（学会ではないが影響力大）

- Google I/O、AWS re:Invent、Microsoft Build: ベンダー系の大型発表イベント
- KubeCon + CloudNativeCon: クラウドネイティブ
- PyCon、RubyKaigi など言語コミュニティ系

## 1.2. 効率的なキャッチアップの型

カンファレンスに参加せずとも、以下の型で効率よく流れを追える。

1. **キーノートだけ視聴する**: 全セッションを追う必要はなく、基調講演（1〜2時間、YouTubeにアーカイブされる）だけで主要発表を把握できる。
2. **一次情報の発表直後ブログを読む**: 公式ブログのアナウンス記事が最速の情報源。
3. **まとめ記事で拾う**: Qiita/Zennの「カンファレンスレポート記事」で要点だけ拾う。
4. **ニュースレターを購読してノイズを減らす**: 例）TLDR AI、Import AI 系。
5. **週1でHacker Newsのトップページを流し見する。**

分野別の一次情報源:

- AI/ML: Hugging Face Papers（日次で注目論文をキュレーション）、Papers with Code Trending（実装付きで話題の論文が追える）。学会そのものよりarXiv + Twitter/Xの研究者コミュニティの方が速報性は高い。
- Web開発: State of JS / State of CSS（年次サーベイでエコシステムの流行がわかる）。

実務では「カンファレンス速報・まとめ記事」を書くこと自体がトレンド把握とアウトプットを両立させる良い手段になる。

## 1.3. 現状のログ（2026-08-02時点）

2026年8月時点の全体的な技術トレンドは大きく3軸で動いている。

### 1.3.1. AI: 「生成」から「実行」フェーズへ

- 2024年がLLM普及、2025年がAIエージェントの実験期だったのに対し、2026年はエージェントが実務で使われる実行フェーズに入っている。
- フィジカルAI: デジタル領域に閉じていたAIが、ロボティクスなど現実世界と統合し自律的に動く方向へ進化。
- スモールランゲージモデル（SLM）: 運用コストの低さと特定タスクでの精度の高さから、巨大LLM一辺倒からの分散が進行。
- AIネイティブ開発基盤: 最初からAI活用を前提に設計されたプラットフォームが台頭。
- AIリスク・ガバナンス: Gartnerは「AIに起因する法的請求」が年末までに2,000件超に達すると予測。規制・責任問題が実務レベルの課題化。

### 1.3.2. ソフトウェア開発: AIが「協働者」化

- Google・Microsoftなどではコードの約25〜30%がAI生成という報告があり、Cursor・Claude Codeのようなツールがリファクタリングやアーキテクチャレビューまで担い始めている。
- クラウドネイティブが前提条件化: Kubernetes・マイクロサービス・サービスメッシュ（[[サービスメッシュ]]）はもはや「先進的」ではなく標準装備。マルチクラウド/ハイブリッドが戦略から運用の現実へ。
- セキュリティが技術リーダーの最優先課題に。

### 1.3.3. 人材・スキル面の変化

- 技術力だけでなく、コミュニケーション力や戦略的思考が技術スキルと同等に評価され始めている。AIが実装を肩代わりする分、要件定義・意思決定・レビューの比重が人間側に残る。

## 1.4. 現状のログ（2026-09-19時点）

2026年9月時点でのグローバル技術トレンドを俯瞰すると、個別技術の進化よりも「何が競争優位の源泉になっているか」が移り変わっている点が本質的。

### 1.4.1. AIエージェント導入は「幻滅期」のパターンに合致

- 企業の79%がAIエージェントを何らかの形で試験導入している一方、本番でスケールできているのは23%にとどまる。Gartnerは2027年までにエージェント型AIプロジェクトの40%超が中止されると予測。
- これはRPA・ビッグデータ・ブロックチェーンなど過去の技術サイクルで繰り返されてきた「幻滅期（Trough of Disillusionment）」の典型パターンであり、驚くべき現象ではなく想定通りの推移と捉えるべき。
- 今後の差別化要因は生成AIの技術力そのものよりも、エージェントの評価基盤・ガバナンス・失敗からの復旧設計に移る。

### 1.4.2. インフラのボトルネックが GPU → メモリ → 電力 の順に移動

- AI半導体は製造数量ではわずか0.2%だが半導体産業の売上の約50%を占める偏った構造。GPU供給難に加え、HBMやDDR4のようなメモリの需給逼迫（一部で前年比26倍の価格上昇）が新たな制約になっている。
- さらに直近ではデータセンターの**電力供給能力**が最大のボトルネックに移行。世界のデータセンター電力消費は2026年に約1,050TWh規模（国に例えると世界5位の電力消費国相当）に達する見込みで、資本や技術よりも電力網の物理的な供給力がAIインフラ拡張の律速要因になっている。
- 結果として、GW級の再生可能エネルギー調達契約（例: Microsoft-Brookfieldの10.5GW契約）を結べる超大手だけが計算資源を確保できる構造となり、「計算資源の民主化」とは逆に寡占が強まる方向に働いている。

### 1.4.3. オープンウェイトモデルの地政学: 中国勢の「ハードで負けてエコシステムで勝つ」戦略

- 米国が世界のAI計算資源の約75%を掌握し、中国は先端チップの禁輸下にあるにもかかわらず、オープンウェイトモデル（Moonshot「Kimi K3」、DeepSeek、Alibaba等）の実力では中国発ラボが世界をリードしている。
- ハードウェアで直接競争できない分、無償配布によって開発者エコシステムへの浸透とロックインを狙う非対称戦略と解釈できる（Androidの普及戦略と同型のロジック）。
- ただしオープンモデルは利用（トークン量）の20%を占める一方、収益シェアはわずか4%という経済的逆説を抱えており、開発・維持側の持続可能性には疑問符が残る。

### 1.4.4. 規制の三極化: EUは「義務化延期」と「罰則発動」を同時に進行

- EU AI Actは高リスクAIの義務化スケジュールを最大16か月延期する一方、罰則規定（違反時に最大で世界売上高7%）は予定通り発効させた。
- これは産業競争力への配慮から運用面は緩めつつ、原則としての規制の看板は下ろさないという政治的妥協であり、EU規制が事実上の世界標準になる「Brussels Effect」が弱まりつつあるシグナルと読める。
- 米国（大統領令＋州法のパッチワーク）、中国（国家管理型の生成AI管理弁法）と合わせ、規制モデルの三極化が定着しつつある。

### 1.4.5. 価値の移動先: コアのコモディティ化と補完財への競争優位シフト

- オープンウェイトモデルの急速なキャッチアップにより、モデル性能そのものの差は縮小し続けている。
- 一方で実際の競争優位は、電力・インフラへのアクセス、巨額資本での長期契約力、配布・エコシステム支配力、データ主権をめぐる各国の政策対応という「補完財」側に移動している。
- これはクレイトン・クリステンセンの「魅力的な利益の保存則」がAI産業全体に当てはまる構図であり、個別トレンドを串刺しに理解する軸になる。

### 1.4.6. 日本の位置取り: 正面対決を避けたニッチ戦略

- 政府は成長戦略の重点分野の筆頭に「AI・半導体」を置き、国産LLM開発への計算資源・補助金支援や機微データの国内保持を含む「ソブリンAI」構築を推進している。
- ただし電力・資本規模で米中に及ばない構造的制約を踏まえ、フロンティアLLMでの正面対決ではなく、製造業の強みを活かした「AIロボティクスでの世界シェア獲得（2040年に世界シェア3割超・20兆円市場目標）」に照準を絞る戦略は、資源制約下での現実的なニッチ選択と評価できる。

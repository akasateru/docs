# 1. SOAR（Security Orchestration, Automation and Response）

セキュリティ運用を効率化するための仕組み・ツール群。日々大量に発生するアラートすべてを手動で調査・対応するのは非現実的なため、定型対応を自動化してアナリストが重要な判断に集中できるようにする。

## 1.1. 3つの構成要素

- **Orchestration（組織化・連携）**: SIEM、EDR、ファイアウォール、脅威インテリジェンスなど、バラバラのセキュリティツール群を連携させ、一元的に操作できるようにする。
- **Automation（自動化）**: 定型的な対応作業（IPのブロック、アカウントの無効化、チケット起票など）をあらかじめ定義した「プレイブック」に沿って自動実行する。
- **Response（対応）**: インシデント発生時に、調査から対処までの一連のワークフローを管理する。

## 1.2. 何を実現するか

- **アラート疲れの軽減**: 定型対応を自動化し、アナリストは重要な判断が必要な事案に集中できる。
- **対応速度の向上**: 検知から対応までの時間（MTTR）を短縮。
- **一貫性の確保**: プレイブックにより、誰が対応しても同じ手順・品質を担保。
- **ケース管理**: インシデントの調査履歴やエビデンスを一元管理。

## 1.3. プレイブック例（フィッシングメール報告）

1. 添付URLを脅威インテリジェンスAPIに照会。
2. 悪意ありと判定されたら、該当URLを自動でブロックリストに追加。
3. 同じメールを受信した他ユーザーを検索し、メールを自動削除。
4. インシデントチケットを自動起票してアナリストに通知。

## 1.4. SIEMとの違い

| | SIEM | SOAR |
| --- | --- | --- |
| 主な役割 | ログ収集・相関分析・検知 | 検知後の対応の自動化・連携 |
| 位置づけ | 「何が起きたか」を見つける | 「起きたことにどう対応するか」を実行する |

両者は連携して使われることが多く、SIEMが検知したアラートをSOARが受け取ってプレイブックを実行する、という流れが一般的。[Security Command Center](../../Cloud/GCP/Security%20Command%20Center.md)のようなクラウドの統合セキュリティ管理サービスにも、Enterpriseティアなどでこうした自動化機能が組み込まれている。

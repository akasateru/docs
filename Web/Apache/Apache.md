# 1. Apache Software Foundation（ASF）

オープンソースプロジェクトを非営利で運営する財団。「Apache」を冠するプロジェクトは350以上あるが、実務で頻出するのはWebサーバー・ビッグデータ基盤・メッセージング・ビルドツールの4系統に集約される。

## 1.1. カテゴリ別の主要プロジェクト

| カテゴリ           | プロジェクト                                          | 役割                                                       |
| ------------------- | ------------------------------------------------------- | ------------------------------------------------------------ |
| Webサーバー        | HTTP Server（httpd）                                   | 世界初期から使われるWebサーバー。「Apache」の語源           |
|                     | Tomcat                                                   | Javaサーブレット/JSPを動かすアプリケーションサーバー         |
| ビッグデータ基盤   | [Hadoop](Hadoop.md)                                     | HDFS・YARNによる分散ストレージ/リソース管理基盤              |
|                     | [Spark](Spark.md)                                        | インメモリ処理による高速な分散データ処理エンジン             |
|                     | Hive                                                     | HadoopデータをSQLライクに操作するクエリエンジン               |
|                     | HBase                                                    | HDFS上に構築されたNoSQL DB（ランダムアクセス向き）            |
| メッセージング/ストリーミング | Kafka                                          | 高スループットな分散メッセージング/イベントストリーミング基盤 |
|                     | Flink                                                    | 低レイテンシなストリーム処理エンジン                          |
|                     | Airflow                                                  | ワークフロー（DAG）のスケジューリング/オーケストレーション    |
|                     | ZooKeeper                                                | 分散システムの協調（リーダー選出・設定共有・ロック）を担う基盤 |
| 検索               | Lucene                                                   | 全文検索ライブラリ                                            |
|                     | Solr                                                     | Lucene上に構築された検索サーバー                              |
| ビルド/インフラ    | Maven                                                    | Javaプロジェクトのビルド/依存管理ツール                       |
|                     | Cassandra                                                | 高可用性重視の分散NoSQL DB（マルチリージョン向き）            |

## 1.2. 選定の目安

- **バッチの大規模分散処理**: [Hadoop](Hadoop.md)（ストレージ）+ [Spark](Spark.md)（処理）の組み合わせが定番。
- **リアルタイム性が必要なストリーム処理**: Kafka（データ連携）+ Flink または Spark Streaming（処理）。
- **定期実行ジョブの依存関係管理**: Airflow でDAGとして表現・スケジューリング。
- **全文検索**: Lucene（ライブラリとして組み込み）か Solr（サーバーとして独立運用）。
- **Java Webアプリのホスティング**: Tomcat（サーブレットコンテナ）。

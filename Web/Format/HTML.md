# HTML

HTML文書の拡張子には`.html`と`.htm`の2種類があるが、機能的な違いはなく、どちらもブラウザ・Webサーバーから同じ`text/html`として扱われる。

## 1. `.htm`が生まれた背景

古いWindows（DOS/Windows 3.1時代）には「8.3形式」と呼ばれるファイル名の制限があり、拡張子は最大3文字までしか使えなかった。`.html`は4文字のため使用できず、代わりに`.htm`が使われた。

## 2. 現在の扱い

8.3形式の制限は現在のOSには存在しないため、拡張子選択は完全に好みや慣習の問題になっている。

- 新規に作成する場合は`.html`が一般的（Unix/Linux系やモダンな開発環境の慣習）
- `.htm`は古いサイトや、Windows由来の一部のCMS・ツールで生成されたファイルに見られる
- 同一サイト内で拡張子を混在させず、どちらかに統一するのが望ましい

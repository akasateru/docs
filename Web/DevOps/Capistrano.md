# 1. Capistrano

Rubyで書かれたオープンソースのリモートサーバー自動化・デプロイツール。SSH経由で複数サーバーに対しコマンドを一括実行できる。元々はRuby on Railsアプリのデプロイ用として広まったが、言語を問わず使える汎用的なタスク実行ツール。

## 1.1. 特徴

- **SSH経由の一括実行**: 複数台のサーバーに対して同時にコマンドを実行できる。
- **設定ファイル**: `Capfile` と `deploy.rb` にタスクや設定を記述。ステージ別の設定は `config/deploy/production.rb` のように分ける。
- **Rubyの拡張性**: DSLがRubyベースなので、プラグインやカスタムタスクで柔軟に拡張できる。

## 1.2. デプロイフローの仕組み

典型的なデプロイの流れは以下の通り。

1. Gitリポジトリから最新コードをサーバーに取得。
2. `releases/` ディレクトリにタイムスタンプ付きディレクトリとして展開。
3. `shared/` 配下の設定ファイル・ログ・アップロードファイルなどをシンボリックリンク。
4. `bundle install` やDBマイグレーション、アセットプリコンパイルなどのフック処理を実行。
5. `current` シンボリックリンクを最新リリースに切り替え（アトミックな切り替え）。
6. アプリケーションサーバー（Unicorn/Pumaなど）を再起動。

## 1.3. メリット

- **ロールバックが容易**: 過去の `releases/` ディレクトリに `current` を戻すだけで即座に切り戻せる。
- **アトミックな切り替え**: シンボリックリンク切り替えのため、デプロイ中のダウンタイムが最小限。
- **マルチサーバー対応**: 複数台への同時デプロイに標準対応。

## 1.4. 現代的な代替との位置づけ

近年はDocker・[Kubernetes](Kubernetes.md)やCI/CD（GitHub Actionsなど）を使ったコンテナベースのデプロイに置き換わるケースが増えている。一方、従来型のVPS/専用サーバー運用（コンテナ化していない環境）では今でもよく使われる。

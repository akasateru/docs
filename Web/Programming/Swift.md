# 1. Swift

Apple製の言語。値型中心の設計とOptional型による安全性重視が特徴。

## 1.1. 特徴

- 値型(struct)中心の設計。
- Optional型でnil安全性を保証。
- ARC(Automatic Reference Counting)によるメモリ管理。

## 1.2. 強み・用途

- iOS/macOSアプリ開発がほぼ唯一無二の主戦場。
- SwiftUIとの統合が強力。

## 1.3. 学習コストとエコシステム

- 学習コストは中程度。
- プラットフォーム外(サーバーサイド等)ではエコシステムが薄い。

## 1.4. 代表的なプロジェクト

- iOSアプリ全般, Vapor(サーバーサイドSwift)

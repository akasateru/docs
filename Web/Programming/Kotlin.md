# 1. Kotlin

JVM上で動作しJavaと完全相互運用可能な言語。Android開発の公式言語。

## 1.1. 特徴

- JVM上で動作し、Javaと完全に相互運用可能。
- null安全な型システム。
- 簡潔な文法。

## 1.2. 強み・用途

- Android開発の公式言語。
- バックエンド(Ktor, Spring)での採用も増加中。
- Kotlin Multiplatformによるクロスプラットフォーム展開が可能。

## 1.3. 学習コストとエコシステム

- 学習コストは低め。Java経験があればほぼそのまま移行可能。

## 1.4. 代表的なプロジェクト

- Androidアプリ全般, JetBrains製品

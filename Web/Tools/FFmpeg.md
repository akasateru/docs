# FFmpeg

動画・音声の処理でよく遭遇するエラーの読み方。

## 1. `partial file` エラー

```text
[mov,mp4,m4a,3gp,3g2,mj2 @ 000001e90defacc0] stream 1, offset 0xc4c79e2d: partial file
```

**意味**: 動画・音声ファイルを処理中に、ファイルが途中で切れている（不完全）ことを示すエラー。

### 1.1. 内訳

- `stream 1`: 2番目のストリーム（通常は音声トラック）に問題がある
- `offset 0xc4c79e2d`: ファイルの特定のバイト位置で問題を検出
- `partial file`: ファイルが完全にダウンロード・保存されていない、または破損している

### 1.2. 主な原因

- ダウンロードが途中で中断されたファイルを処理しようとした
- 録画・エンコード中にクラッシュして中途半端に保存された
- ストレージエラーによるファイル破損

### 1.3. 対処法

1. **再ダウンロード**: ファイルの取得元から再度取得する
2. **FFmpegで再コンテナ化**: `ffmpeg -i input.mp4 -c copy output.mp4`
3. **タイムスタンプ補完**: `-fflags +genpts` オプションを追加して欠損タイムスタンプを補完しながら処理する

処理自体は続行されることが多いので、出力ファイルが正常に生成されていれば実害ない場合もある。

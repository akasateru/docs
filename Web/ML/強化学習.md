## 1. 強化学習とは

エージェントが環境と相互作用しながら、得られる報酬を最大化するように行動方針（policy）を学習する機械学習の一分野。正解ラベルを与える教師あり学習とは異なり、「行動 → 報酬というフィードバックのみ」を頼りに試行錯誤で学習する点が特徴。

### 1.1. 基本構成要素

- **エージェント**: 意思決定をする主体
- **環境**: エージェントが行動する対象
- **状態（state）**: 環境の現在の様子
- **行動（action）**: エージェントが選べる選択肢
- **報酬（reward）**: 行動の良し悪しを示すスカラー値
- **方策（policy）**: 状態から行動を決める関数

### 1.2. 探索と活用のトレードオフ

学習中は「今の知識で最良の行動を選ぶ（活用 / exploitation）」だけでなく、「まだ試していない行動を試す（探索 / exploration）」も必要。よく使われるのが **ε-greedy**: 確率 ε でランダム行動、それ以外は現時点で最良の行動を選ぶ。

## 2. Q学習

価値ベースの強化学習アルゴリズム。状態 `s` で行動 `a` を取った場合の期待累積報酬を表す **Q値（行動価値関数）** `Q(s, a)` を、全ての状態×行動の組み合わせについて表（Qテーブル）として学習する。

### 2.1. 更新式

```text
Q(s, a) ← Q(s, a) + α [ r + γ・max_a' Q(s', a') − Q(s, a) ]
```

- `α`（学習率）: 更新の強さ
- `γ`（割引率）: 将来の報酬をどれだけ重視するか（0〜1）
- `r`: 実際に得た報酬
- `s'`: 行動後の次状態
- `max_a' Q(s', a')`: 次状態で取りうる最良の行動の価値

実際に取った行動の方策とは別に「次状態での最良行動」を仮定して更新するため、この性質を **off-policy** と呼ぶ。

### 2.2. 限界

状態や行動の数が多い、または連続値の場合、Qテーブルをそのまま持つのは組み合わせ爆発により現実的でない。この限界が3章のDQNで解決される。

### 2.3. コード例（Qテーブル方式）

```python
import numpy as np
import gymnasium as gym

env = gym.make("FrozenLake-v1", is_slippery=False)

n_states = env.observation_space.n
n_actions = env.action_space.n

# Qテーブルを0で初期化 → [状態, 行動] の表そのもの
Q = np.zeros((n_states, n_actions))

alpha = 0.1     # 学習率
gamma = 0.99    # 割引率
epsilon = 0.1   # 探索率（ε-greedy）

for episode in range(5000):
    state, _ = env.reset()
    done = False
    while not done:
        if np.random.rand() < epsilon:
            action = env.action_space.sample()
        else:
            action = np.argmax(Q[state])

        next_state, reward, terminated, truncated, _ = env.step(action)
        done = terminated or truncated

        best_next = np.max(Q[next_state])
        Q[state, action] += alpha * (reward + gamma * best_next - Q[state, action])

        state = next_state

# 学習後: 各状態でargmaxを取れば最適行動
```

更新式がそのままコード中の1行（`Q[state, action] += ...`）になっている。

## 3. DQN（Deep Q-Network）

Q学習のQテーブルをニューラルネットワークで近似した手法。DeepMindがAtariのゲームをピクセル入力のみから人間超えのスコアで攻略したことで有名になった。状態が画像などQテーブルで持ちきれない場合に用いる。

### 3.1. 損失関数

```text
Loss = ( r + γ・max_a' Q(s', a'; θ⁻) − Q(s, a; θ) )²
```

Q学習の更新式のズレ（TD誤差）をそのまま二乗誤差として学習する。`θ` は学習中のネットワーク、`θ⁻` はターゲットネットワーク（後述）。

### 3.2. 学習を安定させる2つの工夫

1. **Experience Replay（経験再生）**: 過去の経験 `(s, a, r, s')` をバッファに貯め、ランダムサンプリングして学習に使う。時系列で連続したデータをそのまま使うと相関が強すぎて学習が偏るのを防ぐ。
2. **Target Network（ターゲットネットワーク）**: 学習中のネットワークとは別に、一定間隔でコピーして固定するネットワーク。教師信号自体が毎回動くと学習が発散しやすいため、ターゲット側を一時的に固定して安定化させる。

### 3.3. Q学習との対応関係

| Q学習 | DQN |
|---|---|
| Qテーブル（状態×行動の表） | ニューラルネットワーク |
| 表の書き換え | 勾配降下による重み更新 |
| 離散・小規模な状態空間向け | 高次元・連続的な入力（画像など）にも対応可能 |

### 3.4. 発展形

- **Double DQN**: 行動選択と価値評価を別ネットワークで行い、Q値の過大評価を抑制
- **Dueling DQN**: 状態価値とアドバンテージ（行動の相対的な良さ）を分離して学習
- **Rainbow**: 上記含む複数の改良を統合

### 3.5. コード例（PyTorch）

```python
import torch
import torch.nn as nn
import torch.optim as optim
import random
from collections import deque

class QNetwork(nn.Module):
    def __init__(self, state_dim, n_actions):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, n_actions),
        )

    def forward(self, x):
        return self.net(x)

q_net = QNetwork(state_dim=4, n_actions=2)
target_net = QNetwork(state_dim=4, n_actions=2)
target_net.load_state_dict(q_net.state_dict())

optimizer = optim.Adam(q_net.parameters(), lr=1e-3)
replay_buffer = deque(maxlen=10000)

gamma = 0.99
batch_size = 64

def train_step():
    if len(replay_buffer) < batch_size:
        return
    batch = random.sample(replay_buffer, batch_size)
    states, actions, rewards, next_states, dones = zip(*batch)

    states = torch.tensor(states, dtype=torch.float32)
    actions = torch.tensor(actions).unsqueeze(1)
    rewards = torch.tensor(rewards, dtype=torch.float32)
    next_states = torch.tensor(next_states, dtype=torch.float32)
    dones = torch.tensor(dones, dtype=torch.float32)

    q_values = q_net(states).gather(1, actions).squeeze()

    with torch.no_grad():
        max_next_q = target_net(next_states).max(1)[0]
        target = rewards + gamma * max_next_q * (1 - dones)

    loss = nn.functional.mse_loss(q_values, target)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

for episode in range(1000):
    state, _ = env.reset()
    done = False
    while not done:
        action = q_net(torch.tensor(state, dtype=torch.float32)).argmax().item()
        next_state, reward, terminated, truncated, _ = env.step(action)
        done = terminated or truncated

        replay_buffer.append((state, action, reward, next_state, done))
        train_step()
        state = next_state

    if episode % 10 == 0:
        target_net.load_state_dict(q_net.state_dict())
```

Q学習の「表を直接書き換える1行」に対し、DQNは「ネットワークの予測値を正解（ターゲット）に近づけるよう学習させる」通常のニューラルネット学習と同じ形に落とし込んでいる違いがある。

## 4. GenAI文脈での応用

LLM分野では、人間の好みや正解報酬に沿ってモデルを微調整する手法として **RLHF**（Human Feedback付き強化学習）や **RLAIF**、近年は **GRPO** などが使われている。

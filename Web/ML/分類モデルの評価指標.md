# 分類モデルの評価指標（Precision / Recall / F1）

二値分類モデルの性能を測る代表的な指標群。混同行列（Confusion Matrix）を土台に、Precision・Recall・F1を使い分ける。

## 1. 混同行列（Confusion Matrix）

予測結果と実際の正解を突き合わせた表。

|  | 実際: Positive | 実際: Negative |
|---|---|---|
| **予測: Positive** | TP (True Positive) | FP (False Positive) |
| **予測: Negative** | FN (False Negative) | TN (True Negative) |

- 対角線（TP・TN）＝正解した予測
- 反対の対角線（FP・FN）＝間違えた予測

### 1.1. 名前の読み方のコツ

`T/F` と `P/N` の組み合わせで、**後ろ→前の順**に読むと意味が取れる。

- 後ろの `P`/`N` → 「何と予測したか」
- 前の `T`/`F` → 「その予測が当たった(True)か外れた(False)か」

例: `FP` = 「Positiveと予測した（P）」が「外れた（F）」＝本当はNegativeだった＝**誤検知（過検知）**
例: `FN` = 「Negativeと予測した（N）」が「外れた（F）」＝本当はPositiveだった＝**見落とし（見逃し）**

語呂: 「**F**が付いたら**外れ**、**T**が付いたら**当たり**」

### 1.2. 日本語用語との対応

| 日本語 | 略称 | 意味 | 関連指標 |
|---|---|---|---|
| 誤検知（過検知） | FP | 陰性なのに陽性と判定 | Precisionが下がる |
| 見落とし（見逃し） | FN | 陽性なのに陰性と判定 | Recallが下がる |

## 2. Precision（適合率）

$$
\text{Precision} = \frac{TP}{TP + FP}
$$

「陽性と予測したうち、実際に陽性だった割合」。**誤検知の少なさ**を表す指標。閾値を厳しくする（陽性と判定しにくくする）と上がりやすい。

## 3. Recall（再現率）

$$
\text{Recall} = \frac{TP}{TP + FN}
$$

「実際の陽性のうち、正しく検出できた割合」。**見落としの少なさ**を表す指標。閾値を緩くする（陽性と判定しやすくする）と上がりやすい。

## 4. トレードオフの関係

閾値を動かすと、PrecisionとRecallはシーソーのように逆方向に動く。

- 閾値を下げる（陽性判定を増やす）→ Recall↑・Precision↓
- 閾値を上げる（陽性判定を減らす）→ Recall↓・Precision↑

極端な例で理解できる:

- 全部「陰性」と予測するモデル → FN最大 → Recall = 0（見落としだらけ）
- 全部「陽性」と予測するモデル → FP最大 → Precisionが低下（誤検知だらけ、Recallは1.0だが無意味）

## 5. F1スコア

$$
F1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}
$$

PrecisionとRecallの調和平均。両者はトレードオフの関係にあるため、片方だけを見て「良いモデル」と判断しないためのバランス指標として使う。

## 6. どちらを重視すべきかはドメイン次第

誤検知（FP）と見落とし（FN）のどちらのコストが高いかで、重視すべき指標が変わる。

| ドメイン | 誤検知（FP）のコスト | 見落とし（FN）のコスト | 重視する指標 |
|---|---|---|---|
| がん検診 | 精密検査の手間・費用 | 命に関わる | Recall重視 |
| スパムフィルタ | 大事なメールが届かない | 迷惑メールが少し届く程度 | Precision重視 |
| 不正送金検知 | 正規取引がブロックされる | 不正送金を見逃し損害発生 | 両方重要（F1やコスト関数で調整） |
| 検索エンジン | 関係ない結果が混ざる | 欲しい情報が出てこない | バランス（F1） |

## 7. 具体例（スパムメール判定）

100通のメール（本当のスパム10通、普通90通）に対し、モデルが12通を「スパム」と判定したケース。

|  | 実際:スパム | 実際:普通 |
|---|---|---|
| 予測:スパム | 8通 (TP) | 4通 (FP) |
| 予測:普通 | 2通 (FN) | 86通 (TN) |

- Precision = 8/(8+4) = 0.67 → スパムと判定した12通のうち8通が的中
- Recall = 8/(8+2) = 0.80 → 本当のスパム10通のうち8通を検出
- F1 = 2×(0.67×0.80)/(0.67+0.80) ≈ 0.73

# 機械学習とニューラルネットワークの基礎

AI（特に深層学習・LLM）が内部で何をしているかを、学習と推論の仕組みから整理する。

## 1. AIの分類

- ルールベース: 人間が条件分岐を明示的に記述する。学習しない。
- 機械学習(ML): データから規則性を自動で見つけるアルゴリズム。
- 深層学習(Deep Learning): MLの一種で、多層のニューラルネットワークを使う。画像・音声・言語など複雑なパターンに強い。
- 現在主流のLLM（Claude、GPT等）は深層学習の中の**Transformer**というアーキテクチャを使う（詳細は[LLM](../LLM/LLM.md)参照）。

## 2. 機械学習の学習原理

機械学習は「入力→出力」の対応関係を、大量の例から近似する関数を作る手続き。

1. モデルは大量のパラメータ（重み）を持つ数式（関数）
2. 訓練データを入力し、予測値を出す
3. 正解との差を**損失関数(loss)**で計算する
4. 損失が小さくなる方向にパラメータを更新する（**勾配降下法**）。ニューラルネットでは**誤差逆伝播法(backpropagation)**で各層の勾配を計算する
5. 上記を大量に繰り返すことで、入力から適切な出力を返す関数が出来上がる

「学習」はこのパラメータ調整のプロセスを指し、「推論」は学習済みの固定パラメータで新しい入力に対し出力を計算することを指す。

## 3. ニューラルネットワークの仕組み

- 入力を数値ベクトルに変換する（例: 単語→トークン→埋め込みベクトル）
- 「線形変換（行列積）→ 非線形関数（活性化関数）」を何層も重ねて構成する
- 層を重ねるほど、単純な特徴（エッジなど）から複雑な特徴（文脈・概念）まで段階的に表現できるようになる
- 計算の実体は「巨大な行列演算の連続」であり、これをGPU等で並列計算している

## 4. LLMにおける適用

- **事前学習(Pretraining)**: インターネット規模のテキストで「次のトークンを予測する」タスクのみを学習させる。これだけで文法・知識・推論パターンをある程度獲得する
- **追加調整(Fine-tuning/RLHF)**: 事前学習後に、人間の意図・好みに沿った応答をするよう追加調整する
- **推論時の動き**: プロンプトを受け取り、次に来る可能性が最も高いトークンを確率分布から1つずつ選んで生成する処理を繰り返しているだけ。「思考している」ように見えるが、機械的には「次の単語予測」の連鎖
- Transformer・Self-Attentionの詳細は[LLM](../LLM/LLM.md)の該当セクションを参照

## 5. まとめ

| 段階 | やっていること |
|---|---|
| 学習前設計 | アーキテクチャと目的関数（損失関数）を決める |
| 事前学習 | 大量データで予測タスクを繰り返し、パラメータを最適化 |
| 追加調整 | 人間の意図に沿うよう微調整 |
| 推論 | 固定パラメータで入力から出力を逐次生成 |

LLMは「言葉の統計的パターンを巨大な関数で近似し、次に来る単語を予測し続ける仕組み」であり、内部に明示的な思考プロセスや事実データベースを持つわけではない、という点は誤解されやすい。

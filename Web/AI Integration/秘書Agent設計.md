# 秘書Agent設計

ユーザーの代わりにスケジュール管理・メール対応・タスク管理などをこなすAIエージェントを設計する際の要点。

## 1. 基本構成要素

- **入力チャネル**: チャット経由での都度指示、または定時トリガー（毎朝のブリーフィング等）による自律起動
- **外部ツール連携**: Gmail・Google Calendar等のMCPサーバーを介して、メール検索・返信下書き作成、予定確認・作成などを行う
- **定期実行**: cron的な仕組みで「毎朝ブリーフィング」のような定型タスクを自動化する

## 2. 権限設計

- メール送信・予定変更・削除など「取り返しがつかない/他者に見える」操作は、実行前に必ずユーザー確認を挟む設計にする
- 逆に「検索」「下書き作成（未送信）」「読み取り専用の確認」は確認なしで自動化してよい
- 権限区分の考え方は[LLM](../LLM/LLM.md)の「エージェント型システムの分類（ワークフロー vs エージェント）」の議論とも関連する。自由度を上げるほど誤動作リスクとのトレードオフが生じる

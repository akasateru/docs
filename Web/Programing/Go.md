# 1. Go

シンプルな文法と言語レベルの並行処理サポートを特徴とする、Google製のサーバーサイド向け言語。

## 1.1. 特徴

- 文法が意図的に小さく設計されており、学習コストが低い。
- GC付きだが、goroutineとchannelによる並行処理が言語仕様に組み込まれている。

## 1.2. 強み・用途

- サーバーサイド・マイクロサービス、CLIツールに強い。
- ビルドが速く、単一バイナリとして配布しやすい。

## 1.3. 学習コストとエコシステム

- 学習コストは低い。言語仕様自体が小さいため習得が速い。

## 1.4. 代表的なプロジェクト

- Docker, Kubernetes, Terraform

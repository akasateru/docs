# 1. 正規表現

文字列のパターンマッチングを行うための記法。言語によって細部の仕様差はあるが、基本的なメタ文字・量指定子は共通する。

## 1.1. 基本のメタ文字

| 記号 | 意味 | 例 |
|---|---|---|
| `.` | 任意の1文字（改行除く） | `a.c` → `abc`, `axc` にマッチ |
| `^` | 文字列/行の先頭 | `^abc` |
| `$` | 文字列/行の末尾 | `abc$` |
| `\|` | OR | `cat\|dog` |
| `()` | グループ化・キャプチャ | `(ab)+` |
| `[]` | 文字クラス（いずれか1文字） | `[abc]`, `[a-z]`, `[^0-9]`（否定） |

## 1.2. 量指定子（繰り返し）

| 記号 | 意味 |
|---|---|
| `*` | 0回以上 |
| `+` | 1回以上 |
| `?` | 0または1回 |
| `{n}` | ちょうどn回 |
| `{n,}` | n回以上 |
| `{n,m}` | n〜m回 |

デフォルトは**貪欲(greedy)**。量指定子に `?` を付けると**非貪欲(lazy)**になり、最短マッチを取る。

- `<.+>` → `<a><b>` 全体にマッチ（greedy）
- `<.+?>` → `<a>` だけにマッチ（lazy）

## 1.3. 定義済み文字クラス

| 記号 | 意味 |
|---|---|
| `\d` | 数字 `[0-9]` |
| `\D` | 数字以外 |
| `\w` | 英数字+アンダースコア `[a-zA-Z0-9_]` |
| `\W` | それ以外 |
| `\s` | 空白（スペース、タブ、改行など） |
| `\S` | 空白以外 |
| `\b` | 単語境界 |

## 1.4. グループとキャプチャ

- `(abc)` : 通常のキャプチャグループ。後で `$1` や `\1` として参照できる。
- `(?:abc)` : 非キャプチャグループ。グループ化だけしたい場合に使い、参照コストを避けられる。
- `(?<name>abc)` : 名前付きキャプチャ。

## 1.5. 先読み・後読み（lookaround）

マッチ位置の前後を条件にできるが、その部分自体は消費（マッチ結果に含まれない）しない。

| 記号 | 意味 |
|---|---|
| `(?=...)` | 肯定先読み：続きに`...`があること |
| `(?!...)` | 否定先読み：続きに`...`がないこと |
| `(?<=...)` | 肯定後読み：直前に`...`があること |
| `(?<!...)` | 否定後読み：直前に`...`がないこと |

例: `\d+(?=円)` は「1000円」から `1000` だけを取得できる（`円`は消費されない）。

## 1.6. よく使うフラグ（JavaScript基準）

| フラグ | 意味 |
|---|---|
| `g` | グローバル（文字列全体から全マッチを検索） |
| `i` | 大文字小文字を無視 |
| `m` | 複数行モード（`^`/`$`が各行の先頭/末尾にマッチ） |
| `s` | `.`が改行にもマッチするようになる |

## 1.7. 実用例

```text
メールアドレス: ^[\w.+-]+@[\w-]+\.[a-zA-Z]{2,}$
郵便番号(日本): \d{3}-\d{4}
半角数字のみ:   ^\d+$
先頭末尾の空白: ^\s+|\s+$
```

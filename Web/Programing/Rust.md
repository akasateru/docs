# 1. Rust

所有権(ownership)とボローチェッカーにより、GC無しでメモリ安全性をコンパイル時に保証する言語。

## 1.1. 特徴

- 所有権システムとボローチェッカーがメモリ安全性を静的に保証し、実行時オーバーヘッドが小さい。
- GCを持たないため、レイテンシが予測しやすい。

## 1.2. 強み・用途

- パフォーマンスが要求される場面(OS、組込み、WebAssembly、CLIツール)に強い。
- 並行処理の安全性がコンパイル時に検証される(データ競合を型システムで防ぐ)。

## 1.3. 学習コストとエコシステム

- 学習コストは高め。ボローチェッカーとの折り合いをつける過程が最初の壁になりやすい。

## 1.4. 代表的なプロジェクト

- ripgrep, deno, Firefoxの一部, TiKV

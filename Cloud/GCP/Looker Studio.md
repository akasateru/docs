# 1. Looker Studio

Googleが提供する無料のBI・データ可視化ツール（旧Google Data Studio）。データソースに接続してダッシュボード・レポートを作成する。

## 1.1. 特徴

- **無料**：Googleアカウントがあれば利用可能。有料版の Looker Studio Pro もあり、権限管理やSLAが強化される。
- **多様なデータソース接続**：Googleスプレッドシート、BigQuery、Google Analytics（GA4）、Google広告、Cloud SQL など300以上のコネクタ（サードパーティ含む）に対応。
- **リアルタイム連携**：データソース更新がキャッシュ設定に応じて反映される。
- **共同編集**：Googleドキュメントのように複数人で同時編集・コメントが可能。
- **埋め込み**：作成したレポートをWebサイトへ埋め込み可能。

同じくGoogle系のBIプラットフォームである [Looker](Looker.md) とは別製品。Looker Studio は軽量・無料のセルフサービスBI、Looker はエンタープライズ向けの本格的なBIプラットフォーム（LookML でのモデリングなど）という位置付けの違いがある。

## 1.2. 構成要素

| 要素 | 説明 |
|---|---|
| データソース（Data Source） | 接続元データの定義。フィールドの型変換・計算フィールドの作成もここで行う。 |
| レポート（Report） | 実際に見せるダッシュボード。複数ページで構成可能。 |
| グラフ（Chart） | 表、時系列、棒グラフ、円グラフ、地図、スコアカードなど。 |
| コントロール（Control） | 日付範囲・プルダウンフィルタなどのインタラクティブ要素。 |
| 計算フィールド | SQLライクな関数（`CASE WHEN`、`SUM`、`REGEXP_MATCH` 等）で新規指標を定義する機能。 |

## 1.3. 注意点

- **[BigQuery](BigQuery.md)のクエリコスト**：フィルタやページ切替のたびにクエリが発行されるため、大きいテーブルではコスト・速度に注意が必要。抽出データ（データ抽出）機能やキャッシュ設定、事前集計ビューの用意で対策する。
- **データソースとレポートの分離**：同じデータソースを複数レポートで使い回せる一方、フィールドの変更は紐づく全レポートに影響する。
- **結合（Blend Data）の制限**：複数データソースの結合はLEFT OUTER JOINベースで、結合キー数などに制約がある。複雑な結合はBigQuery側で事前にJOINしておく方が安定する。
- **権限**：データソースの「編集者権限で表示」設定によっては、閲覧者が元データへ直接アクセスできてしまう場合があるため要注意。
